# EMURU v0.3.4 release report

Package version: `0.3.4`. Status: implemented; live acceptance pending.

## Delivered

- One explicit qualification command validates the selected Ollama cloud/local
  pair against an isolated synthetic vault. It never automates real-vault writes.
- Private v2 evidence binds both model identities, local digest, Ollama runtime
  and template, context/reserve, workload policy, expiry and canonical fingerprint.
- Tools, workload, context, latency, hardware and fault gates must all pass before
  the route updates. Failure preserves the route and reports `LOCAL_UNQUALIFIED`.
- Gateway admission rechecks evidence, live model/digest/runtime/template and
  request context before local dispatch. Completed or malformed results do not fail over.
- Deterministic qualification, evidence invalidation, threshold, isolation,
  redaction and failed-run preservation checks run in CI with gateway tests.

## Manual acceptance gaps

Live provider/model quality, host performance, offline-local proof on target
hardware, and Telegram delivery were not run in CI. Manually issue one read-only
real-vault retrieval/navigation request through cloud. Then repeat during a
controlled eligible primary outage through qualified local. Confirm no real-vault
mutation, restore primary, and confirm primary recovery. Docker/systemd cutover
and continuous monitoring remain v0.4.0 work.
