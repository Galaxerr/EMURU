# EMURU v0.3.3 release report

Branch: `feat/v0.3.3-gateway-fallback`. Package version: `0.3.3`.
Status: complete.

## Delivered

- CLI and guarded Telegram use only authenticated LiteLLM `emuru` inference,
  including context compression. TUI and inference overrides are rejected.
- Each call starts with one cloud attempt. Eligible Ollama Cloud availability
  failures permit at most one qualified local attempt; Gemini/OpenAI do not.
  Hermes retries, recovery and provider fallback remain disabled.
- Local admission requires matching digest, runtime, template, context/counting
  evidence and unexpired qualification. The picker leaves qualification null.
- Buffered streams and tool arguments are validated before exposure. Budgets
  are 60 seconds cloud, 180 local, 245 per routed call and 600 per owner turn.
  Cancellation and stale-owner guards suppress late inference/tool dispatch.
- Telegram preserves durable receipts, serialized execution, at-most-once
  notices and conservative reporting of completed or uncertain effects.
